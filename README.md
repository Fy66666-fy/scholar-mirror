# 文献镜像 ScholarMirror

跨学科文献摘要与关联分析系统。**不调用大模型、不需要 API Key、不花额度**，摘要与结论全部由本地算法从原文抽取。

它是 [med-lit-system](../medical-lit-system) 的镜像版：那套系统只做医学，这一套把「学科模板」抽出来做成了可插拔的层，
医学、计算机、经济、社科、人文、工程各有各的摘要结构；同时在医学版的基础上补了三件它没有的事 ——
**三层查重、关联图谱、研究缺口与方向建议**。

```
检索（6 个源并发）→ 跨源去重 → 结构化摘要 → 查重 → 关联图谱 → 主题聚类 + 精选 → 缺口与方向 → 导出
```

## 快速开始

```bash
pip install -r requirements.txt
streamlit run app.py
```

Windows 直接双击 `启动.bat`（会自动找解释器、缺依赖时自动装）。默认端口 8601。

**没有网络也能看效果**：首页点「先看演示数据」，或访问 `http://localhost:8601/?demo=1`，
会载入 12 篇跨学科示例文献（含一对预印本/正式版、一条跨源重复记录），走的是和真实检索完全相同的分析链路。

第一次用建议：首页输入 `microplastics soil microbial community` → 看检索结果 → 依次点「摘要工坊 / 关联图谱 / 主题聚类 / 缺口与方向」。

## 它解决什么

读一批论文的真实流程是：找到 → 读完 → 排重 → 归类 → 找空白 → 写成文字。PubMed、Google Scholar 管到「找到」，
后面几步全靠手工。这个工具把后面几步接上，并且**每一步都保留可核对的证据**：

| 步骤 | 做什么 | 怎么保证不瞎编 |
|---|---|---|
| 检索 | 6 个源并发，跨源合并同一篇 | 合并记录里写明「命中哪几个源」 |
| 摘要 | 按学科模板抽 6 个槽位 | 每个槽都是原文原句，带句序号可回溯 |
| 查重 | 三层：跨源 / 近似重复 / 文本 | 只给「疑似」与建议处置，判定留给人 |
| 关联 | 四路信号合成关联度 | 每条边拆成 4 个分项，能看是哪一项在起作用 |
| 聚类 | 层次聚类 + 轮廓系数选 k | 簇名来自「区别于全局的词」，不是 Cluster 1 |
| 精选 | 五项加权排序 | 每项分数单独展示，不认可排序时知道该改哪项 |
| 缺口 | 10 条规则 + 证据原句 | 样本 < 4 篇时只出观察不出结论 |

## 页面

**首页** 说明 + 快速开始 + 数据源状态 + 最近检索。

**文献检索** 检索式支持空格分词、`"精确短语"`、`-排除词`；按学科自动选源；年份下限、仅 OA。
结果页可筛选（年份 / 研究设计 / OA / 排序）、就地看摘要、收藏、导出 BibTeX 与 XLSX。

**摘要工坊** 三种用法：
- *单篇深读*：六个槽位 + 一句话结论 + 关键数值 + 原文定位（哪句落在哪一栏，颜色区分）+ 模板切换
- *批量对比*：3–30 篇横向表格，每格带原句，可导出 Markdown / XLSX
- *粘贴文本*：任何摘要或段落，中英文都行，带不带 `Background:` 小标题都能识别

**查重中心**
- *跨源合并*：列出合并了哪几条、来自哪些源
- *近似重复*：预印本 ↔ 正式版、会议版 ↔ 期刊版、疑似重复发表；四个信号分项打分
- *文本查重*：逐句比对当前文献池，给重复率、命中句、原文出处、来源汇总，可下载报告

**关联图谱** 力导向布局（Fruchterman–Reingold，纯 numpy，固定种子可复现）。节点大小=连接数/被引，
颜色=研究方向；点开任一文献看它最像的 6 篇及分项贡献；另有「跨方向桥梁文献」与关联矩阵热力图。

**主题聚类** 方向卡片（规模、年份跨度、凝聚度、主要设计、代表文献）+ 年份堆叠图 + 设计分布 + 精选清单。

**缺口与方向** 每条缺口：严重度、触发比例、依据、为什么算缺口、怎么补、命中文献原句、可检验的问题；
随后是方向建议（依据缺口 / 推荐设计 / 预期贡献 / 风险与替代）；最后是概念 × 方向覆盖矩阵。

**我的文献库** 分组 + 标签 + 笔记 + 阅读状态，本地 SQLite，可导出 BibTeX / RIS / XLSX。

| 源 | 覆盖 | 这个项目主要用它什么 |
|---|---|---|
| OpenAlex | 全学科 2.5 亿+ | 摘要、主题标签、参考文献 |
| Crossref | 全学科正式出版物 | 权威元数据、卷期页码 |

| PubMed | 生物医学 | MeSH 主题词、结构化摘要 |
| Europe PMC | 生命科学 | OA 全文标记、参考文献 |
| Semantic Scholar | 全学科 | TLDR 一句话摘要（匿名配额紧，失败自动跳过） |

全部免注册。单源失败不影响整体，检索页会显示每个源的条数与耗时。
请求层统一做了磁盘缓存（检索 10 分钟 / 单篇 24 小时）、指数退避重试、按域名限速（arXiv 遵守 3 秒/次）。

## 算法说明

### 摘要：模板 + 统一槽位

模板决定读哪些线索词、按什么顺序呈现；槽位统一收敛到
`question / method / data / findings / conclusion / limitation`，所以跨学科可以直接横向对比。

抽取顺序：
1. 有 `Background/Methods/Results/Conclusions`（或中文 目的/方法/结果/结论）→ 直接按段归属；
2. 没有 → 线索词 × 句位置 × 数字密度算六槽亲和度，全局贪心分配（一句只归一槽）；
3. 仍空 → 按摘要叙述顺序的位置区间补（标记「位置推断」，界面会说明）；
4. 抽不到 → 明确写「摘要未提及」，不生成。

模板：`imrad`（医学/生命/环境）、`cs`（计算机/工程/物理）、`econ`（经济/管理）、
`social`（社科/教育）、`humanities`（人文/理论）、`review`（综述/Meta）。

### 查重

- **跨源合并**：DOI / PMID / arXiv 精确匹配 + 标题前 40 字符分块 + 词集 Jaccard ≥ 0.88；
  DOI 冲突时不合并（那可能是同题两篇）。
- **近似重复**：`0.38×摘要余弦 + 0.30×标题重叠 + 0.17×连续片段覆盖 + 0.15×SimHash`，
  信号缺失时重新归一化权重（否则两条无摘要但标题相同的记录只能拿 0.62 分）。
- **文本查重**：句子级最佳匹配，重复率 = 命中句字符数 × 匹配度 / 总字符数。
  比整篇余弦更敏感：抄两段在整篇余弦里几乎看不出来。

### 关联：四路信号

`文本余弦 0.42 / 概念标签 0.20 / 引用关系 0.30 / 元数据 0.10`，无引用数据时按剩余信号重新归一化。
阈值默认取两两分数的 75 分位而非固定值 —— 绝对相似度在不同主题上不可比。

### 聚类与精选

平均连接层次聚类（允许簇大小悬殊），k 用轮廓系数在 2–8 间选。
精选分 = `影响力 30%（对数压缩被引）+ 新近度 20%（半衰期 5 年）+ 相关度 28% + 完整度 14% + 可获得性 8%`。

### 缺口规则

证据层级、样本规模、随访时长、外部效度（单/多中心）、结论冲突、方法同质化、
概念空白（future work 高频但结论少见）、可复现性、效应量报告、设计信息缺失。
每条规则都要满足最小样本量与触发比例，否则不输出。

```

├── app.py                 入口与路由
├── core/
│   ├── text.py            分句/分词/TF-IDF/SimHash/数值抽取

│   ├── http.py            请求层：缓存/重试/限速/统计
│   ├── sources/           六个数据源适配器 + 并发编排
│   ├── templates.py       学科摘要模板与线索词
│   ├── summarize.py       结构化摘要引擎
│   ├── dedupe.py          三层查重
│   ├── related.py         关联度、图、力导向布局、桥梁文献
│   ├── cluster.py         聚类、簇命名、精选
│   ├── gaps.py            缺口识别与方向建议
│   ├── library.py         本地文献库（SQLite）
│   └── export.py          BibTeX/RIS/Markdown/XLSX
├── ui/
│   ├── theme.py           设计系统与组件
│   ├── state.py           会话状态与分析流水线

├── tests/                 42 个单元测试
└── data/                  缓存与 mirror.db（自动生成）
```

## 边界（请务必读）

- **摘要是抽取式**：不会替你润色、不会跨句改写。读起来不如人写的顺，但不会编造。
- **只看摘要**：所有判断基于标题 + 摘要。摘要没写的（例如正文里的偏倚控制）会被归到「报告完整性」，不是「研究缺陷」。
- **缺口分析不是质量评价**：它报的是「这批文献在哪些维度上同质或缺失」，不能用来给单篇研究打分。
- **结论冲突只提示不裁定**：方向不一致时列出可能原因（人群/剂量/终点/随访），谁对谁错要回原文。
- **聚类边界是人为的**：轮廓系数 0.1 上下说明文献本身连续，方向划分只是便于组织，不是客观分类。
- **语料是摘要**：文本查重只比对摘要与标题，不等于全文查重。

需要严格方法学评价时，请按研究设计使用对应工具（RoB 2 / NOS / AMSTAR-2 / GRADE / SANRA 等）回全文逐条评。
