# 文献镜像 ScholarMirror

跨学科文献**研究工作台**。检索、结构化摘要、查重、关联图谱、主题聚类、研究缺口、个性化推荐、项目管理，全部在本地完成 —— **不调用大模型、不需要 API Key、不花额度**。

它是 [med-lit-system](../medical-lit-system) 的镜像泛化版：那套只做医学，这套把「学科模板」抽成可插拔层，并补上了医学版没有的四件事 —— **三层查重、关联图谱、缺口分析、研究画像与推荐**。

```
建画像 → 检索/导入 → 结构化摘要 → 查重 → 关联与聚类 → 缺口与方向 → 推荐 → 项目与写作 → 导出
```

**状态：开发版（未发布）** —— 版本号在首个公开版本发布时确定。路线图见 [ROADMAP.md](ROADMAP.md)，变更见 [CHANGELOG.md](CHANGELOG.md)。

## 快速开始

```bash
pip install -r requirements.txt
streamlit run app.py
```

Windows 双击 `启动.bat`（自动找解释器、缺依赖自动装）。默认端口 8601。

**没有网络也能看效果**：首页点「先载入演示数据」，或访问 `http://localhost:8601/?demo=1`。
会载入 12 篇跨学科示例（含一对预印本/正式版、一条跨源重复记录），走的是和真实检索完全相同的分析链路。

**第一次用建议的路径**（约 5 分钟）：

1. 「研究画像」加一个方向：标签 + 3–5 个具体关键词
2. 「文献检索」查一次，或「文献库 → 导入」把 Zotero 的 BibTeX 搬进来
3. 收藏几篇 → 「文献库」给它们打标签、写摘录
4. 「研究项目」建一个课题，把文献挂进去，加两个里程碑
5. 回「工作台」：阅读队列、项目进度、方向覆盖都在这一屏
6. 「推荐」生成一次，看它推的是不是你真想读的

## 推荐是怎么算的

推荐是「召回 → 打分 → 去重 → 多样性」四步，没有黑箱：

**召回**：取权重最高的三个方向，各查一轮；再用种子文献标题里信息量最高的词补一轮。

**打分**（五项加权，缺信号时重新归一化）：

| 信号 | 默认权重 | 含义 |
|---|---|---|
| 相关度 | 34% | 关键词命中率 60% + 摘要余弦 40%（纯余弦在「短画像 vs 长摘要」上会被系统性压低） |
| 库内邻近 | 22% | 与文献库已有文献的接近程度 |
| 种子邻近 | 14% | 与种子文献的接近程度 |
| 影响力 | 16% | 被引次数对数压缩 |
| 时效性 | 14% | 半衰期 5 年的指数衰减 |

**去重**：与文献库高度重合（标题 Jaccard ≥ 0.85）的直接剔除。

**多样性**：MMR，λ=0.72，避免 20 条全是同一篇的跟风工作。

界面上五项分数单独展示，不认可排序可以现场调权重后「重排」（不重新联网）。

## 算法说明

### 摘要：模板 + 统一槽位

模板决定读哪些线索词、按什么顺序呈现；槽位统一收敛到 `question / method / data / findings / conclusion / limitation`，跨学科可直接横向对比。

抽取顺序：结构化小标题 → 线索词 × 句位置 × 数字密度全局贪心分配 → 位置区间推断（标注「位置推断」）→ 仍无则写「摘要未提及」。

模板：`imrad`（医学/生命/环境）、`cs`（计算机/工程/物理）、`econ`（经济/管理）、`social`（社科/教育）、`humanities`（人文/理论）、`review`（综述/Meta）。

### 查重

- **跨源合并**：DOI / PMID / arXiv 精确匹配 + 标题前 40 字符分块 + 词集 Jaccard ≥ 0.88；DOI 冲突不合并。
- **近似重复**：`0.38×摘要余弦 + 0.30×标题重叠 + 0.17×连续片段覆盖 + 0.15×SimHash`，信号缺失时重新归一化。
- **文本查重**：句子级最佳匹配，重复率 = 命中句字符数 × 匹配度 / 总字符数。

### 关联与聚类

四信号 `文本 0.42 / 概念 0.20 / 引用 0.30 / 元数据 0.10`，阈值取分位数而非固定值；图布局用 Fruchterman–Reingold（纯 numpy，固定种子可复现）。

平均连接层次聚类（允许簇大小悬殊），k 用轮廓系数在 2–8 间选；簇名优先用作者关键词/主题标签，过滤 arXiv 分类码。

### 缺口规则

证据层级、样本规模、随访时长、外部效度、结论冲突、方法同质化、概念空白、可复现性、效应量报告、设计信息缺失。每条都要满足最小样本量与触发比例，否则不输出；样本 < 4 篇只出观察不出结论。

## 边界（请务必读）

- **摘要是抽取式**：不润色、不跨句改写；读起来不如人写的顺，但不会编造。
- **只看摘要**：正文里写了但摘要没写的，会被归到「报告完整性」而不是「研究缺陷」。全文解析在路线图 P2-A。
- **缺口分析不是质量评价**：它报的是「这批文献在哪些维度上同质或缺失」。
- **结论冲突只提示不裁定**：方向不一致时列出可能原因，谁对谁错要回原文。
- **聚类边界是人为的**：轮廓系数 0.1 上下说明文献本身连续。
- **推荐只依据显式画像**：不训练、不画像你的阅读行为；跨学科经典工作常因关键词不重合被低估。
- **文本查重只比对摘要与标题**，不等于全文查重。

需要严格方法学评价时，请按研究设计使用对应工具（RoB 2 / NOS / AMSTAR-2 / GRADE / SANRA 等）回全文逐条评。
